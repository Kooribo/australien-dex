# Ostküsten-Dex

Ein Pokédex fürs Handy für den Roadtrip an der Ostküste Australiens (Melbourne → Cairns, 25.10.–19.11.).

- 89 Tiere von Land, Wasser und Luft, nummeriert und sortiert nach Größe (#001 = größtes Tier)
- Namen auf Deutsch, Englisch und Latein, dazu Größe, Gewicht, Nahrung und ein Fun Fact
- Gefahrenstufe 1–5 mit Verhaltenstipp, plus Notfall-Infos
- Filter nach Lebensraum, Stopp auf der Route, gefunden/offen und gefährlichen Tieren
- Abhaken zum Sammeln: Gefundene Tiere werden farbig, der Stand bleibt im Browser des Handys gespeichert

Öffnen: `index.html` im Browser, oder über GitHub Pages (Settings → Pages → Branch auswählen).

Dateien: `data.js` (Tierdaten und Route), `credits.js` (Bildnachweise), `img/` (Fotos).

Fotos: Beobachtungen von iNaturalist-Nutzern unter Creative-Commons-Lizenzen (meist CC BY-NC). Urheber und Lizenz stehen in `credits.js` und in der App am jeweiligen Bild.
